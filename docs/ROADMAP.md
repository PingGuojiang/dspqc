# 开发路线图

以下内容为未来方向，尚未实现；优先级可根据反馈调整，不承诺发布日期

## 第一阶段：规划体验和数据可靠性

- [ x] 对齐游戏版本并记录数据更新时间、特殊配方与科技边界
- [x ] 完善普通模式设定面板，提供建筑和增产策略批量设置
- [] 支持 2D 节点布局保存、导入与导出，减少重复整理
- [x ] 增加长生产链的搜索、折叠、分组和性能优化

## 第二阶段：蓝图生成与导出

- [ x] 调研游戏蓝图格式、编码、校验和版本兼容
- [x ] 从生产步骤生成建筑、传送带、分拣器和喷涂机布局
- [x ] 提供行列布局、建筑间距、进出料方向和堆叠配置
- [x ] 支持混带合流、回流优先与输出物流布局校验
- [ ] 导出游戏可导入的蓝图文本或文件，并提供预览与建筑清单
- [ ] 用游戏内导入和实际生产验证蓝图，不以网页预览代替验证

蓝图功能先覆盖确定性制造配方和有限建筑组合，再扩展复杂布局普通模式的生产链节点图表达依赖关系，不含全部物理坐标与连接信息，不能直接视为游戏蓝图球面地形、建筑碰撞、分拣跨距、科技等级和版本变化都需要单独建模

## 第三阶段：模型扩展与生态

- [ ] 完善分馏、光子、充电和采集等特殊生产过程
- [ ] 加入增产剂耗量、物流功耗和建筑部署功耗明细
- [ ] 支持 Mod 数据版本管理及配置迁移
- [ ] 增加结果清单导出、方案对比、模板与多语言支持

建议通过仓库 Issues 提交需求，并附游戏版本、目标方案和预期输出贡献流程见 [贡献指南](../CONTRIBUTING.md)

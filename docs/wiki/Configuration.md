# 配置、分享与导入

两个模式分别保存输入、扩展物品/配方、撤销历史和视图标签切换模式不会覆盖另一个模式

浏览器本地存储自动保存工作区配置清除站点数据或更换浏览器会失去本地记录，可提前使用分享链接备份

分享链接载入其对应模式并保留另一工作区自定义数据包含在该模式链接中；旧 `#s` 链接仍兼容当前页面路径后的 hash 是配置的一部分，不应截断

JSON 导入面向项目识别的游戏数据格式，不保证任意 Mod 文件可直接使用导入前检查结构、物品 ID、配方和图标来源；无效数据会被校验拒绝导入只影响当前模式

“重置当前模式”作用于当前工作区；撤销同样按模式分别管理

# 2D 画布与交互

## 普通模式

- 滚轮以鼠标位置为中心缩放
- 拖动卡片改变节点位置，物料依赖线同步更新
- 拖动空白区域平移画布
- 点击或键盘 Enter/空格选择步骤
- “适应画布”覆盖当前节点范围；“重置视野”恢复默认缩放和平移；“重置布局”恢复自动节点排列

## 混带模式

支持滚轮缩放、拖拽平移、自动缩放、高度选择以及动画/物料标签切换物料动画是示意，不是游戏物理仿真

模式及结果视图切换保留会话内画布状态手动节点布局和视野当前不随刷新或分享保存节点依赖图也不是可导入游戏的蓝图；蓝图生成属于 [未来计划](../ROADMAP.md)
